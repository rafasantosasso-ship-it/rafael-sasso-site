# Rafael Sasso – site pessoal

Site estático (HTML/CSS/JS), bilíngue EN/IT. Sem build.

## Formulário
Usa Netlify Forms: funciona sozinho quando o site é publicado no Netlify.
Depois do primeiro deploy: Netlify → Site → Forms → ative as notificações por e-mail
(Form notifications → Email) para rafasantosasso@gmail.com.

## Publicar
Netlify → Add new site → Import from GitHub (ou Deploy manually arrastando esta pasta).
Domínio: compre na Cloudflare e aponte o DNS para o Netlify.
